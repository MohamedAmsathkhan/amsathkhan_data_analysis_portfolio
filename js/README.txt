PORTFOLIO — FIXED INTERACTIONS

FILES:
- index.html
- style.css
- js/main.js

HOW TO RUN:
1. Keep all files in the correct folder structure.
2. Open the project folder in VS Code.
3. Install and run Live Server.
4. Right-click index.html.
5. Select Open with Live Server.

WORKING FEATURES:
- Project filter buttons
- Inspect Dashboard & Details
- Individual project details
- Summary / By Segment chart toggle
- Interactive charts
- Modal close button
- Click outside to close modal
- Escape key to close modal
- Mobile navigation
- Contact form validation
- Email draft opening
- Typing headline animation
- Count-up metrics
- Animated background
- Back-to-top button
- Active navigation state

IMPORTANT — CONTACT FORM:
The contact form validates the fields and opens the visitor's default email app with a pre-filled message.

It does not send emails automatically.

In js/main.js, find:

const recipient = '';

Replace it with your email address.

Example:
const recipient = 'yourmail@gmail.com';

For automatic website email sending, a backend or email service is required.

IMPORTANT — DASHBOARD:
